# Mini Sistema de Cadastro de Contatos

Este projeto foi desenvolvido com base nos meus estudos, aplicando meus conhecimentos atuais em programação para criar um sistema simples e funcional de cadastro de contatos.

## Contexto do Projeto

O objetivo foi construir uma solução prática e organizada, considerando meu nível atual de aprendizado.  
No momento, ainda estou aprendendo sobre banco de dados, por isso, à princípio, achei viável a utilização do localStorage do navegador para armazenar temporariamente os dados

## Tecnologias Utilizadas

- **JavaScript (puro):** tecnologia escolhida por ser a que tenho mais segurança no momento.
- **localStorage (Chrome):** utilizado para salvar e manter a lista de contatos localmente.
- **CSS puro:** utilizado para estilização da interface, com foco em controle total do layout.

## Observações de Evolução

Atualmente estou iniciando meus estudos em React, mas optei por não utilizar essa tecnologia neste projeto por ainda não me sentir totalmente seguro para aplicá-la neste contexto.

Também tenho breve conhecimento de frameworks de CSS, como o Tailwind, que podem acelerar o desenvolvimento, mas neste projeto preferi usar CSS puro por maior domínio.
